# Nivek First Person

Mod base para **Minecraft 1.21.1 + Fabric + Java 21**.

Esta versão (0.1.0) só carrega e registra uma mensagem no log. As funções de primeira pessoa (pernas, animações) ainda não foram implementadas.

## Compilar pelo GitHub Actions

1. Crie um repositório no GitHub e envie **todos** os arquivos desta pasta (inclusive a pasta oculta `.github`).
2. Abra a aba **Actions**, rode **Build Nivek First Person** (ou faça um push).
3. Ao terminar, baixe o artefato `nivek-first-person-1.21.1` e copie o `.jar` para a pasta `mods` do Minecraft.

## Requisitos para jogar

- Minecraft 1.21.1 com Fabric Loader 0.16.0 ou mais novo
- Fabric API para 1.21.1
- Java 21
